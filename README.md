## Aim:
To apply various UX design techniques such as solution ideation, user stories, scenario creation, user-flow mapping, and information architecture to solve a real-world UX problem.

## Problem Statement:
Design a user-friendly ShopEase E-Commerce Application that allows customers to easily search for products, view product details, add products to the cart, make payments, and track their orders.

## Requirements
1. Canva
2. Figma
3. Paper/Pen for ideation
4. ShopEase E-Commerce Application concept
5. UX design principles

## Algorithm:
1. Identify a common UX problem in the ShopEase e-commerce application.
2. Conduct a Crazy 8s ideation exercise to generate multiple possible solutions.
3. Create low-fidelity sketches for the selected ideas using simple shapes and wireframes.
4. Use the user's goals and persona to create at least five user stories.
5. Select one user story and create a narrative scenario describing the user's environment, actions, and emotions.
6. Create a user-flow diagram showing the steps involved in completing the selected task.
7. Perform card sorting to organize ShopEase features into meaningful categories.
8. Create an Information Architecture (IA) and site map showing the overall structure of the application.
9. Analyze the complete flow and ensure that the application is simple, understandable, and user-friendly.
##
Solution Ideation – Crazy 8s

UX Problem

Users may find it difficult to search, compare, select, and purchase products quickly in an e-commerce application.

Crazy 8s Ideas
1. Quick Search – Search products using a simple search bar.
2. Category Navigation – Provide categories such as Dresses, Shoes, and Accessories.
3. Product Filters – Filter products by price, size, rating, and brand.
4. Product Details – Display image, price, size, rating, and description.
5. Add to Cart – Allow users to quickly add products to their cart.
6. Wishlist – Save products for later.
7. Multiple Payment Options – Provide UPI and other payment methods.
8. rder Tracking – Allow users to track their orders.

##
Creating User Stories

The following user stories were created based on the ShopEase customer persona.

User Story 1

As a customer, I want to search for products, so that I can quickly find what I need.

User Story 2

As a customer, I want to filter products by price and category, so that I can find suitable products easily.

User Story 3

As a customer, I want to view product details, so that I can make an informed purchase decision.

User Story 4

As a customer, I want to add products to my cart, so that I can review them before purchasing.

User Story 5

As a customer, I want to choose a convenient payment method, so that I can complete my purchase securely.

User Story 6

As a customer, I want to receive order confirmation, so that I know my purchase was successful.

##
Creating Scenario

Selected User Story

As a customer, I want to add products to my cart, so that I can review them before purchasing.

Narrative Scenario


Priya is a college student who wants to purchase a new dress using the ShopEase application. She opens ShopEase on her smartphone while sitting at home.

She searches for dresses and browses through the available products. She feels excited when she finds a dress that she likes. She opens the product details to check the price, size, rating, and description.

After selecting the appropriate size, Priya adds the dress to her cart. She checks the cart to verify the product, quantity, size, and total price.

She then proceeds to checkout and selects a suitable payment method. After completing the payment, ShopEase displays an order confirmation message.

Priya feels happy and relieved because she has successfully purchased the product without visiting a physical store.

User Context
User: Priya – College Student
Device: Smartphone
Environment: Home
Task: Purchase a dress through ShopEase
Emotional State: Curious → Excited → Confident → Relieved → Happy
Goal: Purchase a product easily and securely
